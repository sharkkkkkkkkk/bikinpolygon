# Pricing — BikinPolygon GIS Workspace

Informasi tarif resmi dan struktur paket akses BikinPolygon (https://bikinpolygon.xyz/harga). Tidak ada biaya langganan otomatis tersembunyi (non-recurring). Pembayaran instan via QRIS (GoPay, OVO, Dana, BCA, Mandiri, BRI, BNI, ShopeePay, dll).

## Free Tier (Uji Coba Gratis)
- Price: Rp 0
- Billing: Gratis tanpa kartu kredit
- Limits: Maksimal luas polygon 50 m², 1 sesi
- Features:
  - Digitasi batas lahan di atas peta satelit
  - Ekspor Shapefile dasar
  - Penanda titik koordinat latitude/longitude

## Paket Akses Harian (24 Jam)
- Price: Rp 27.000 (sekali bayar via QRIS)
- Billing: Durasi aktif 24 jam penuh sejak pembayaran
- Limits: Tanpa batas luas lahan, tanpa batas jumlah file polygon
- Features:
  - Ekspor 4 berkas Shapefile ZIP lengkap (.shp, .shx, .dbf, .prj)
  - Standar proyeksi WGS 84 (EPSG:4326) & Web Mercator (EPSG:3857)
  - Fitur Koreksi Luas Otomatis sesuai Sertifikat BPN
  - Overlay layer batas persil pertanahan resmi ATR/BPN
  - Ekspor dokumen Laporan Peta PDF resmi
  - Dukungan perizinan KKPR NIB OSS RBA
